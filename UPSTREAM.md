# Source provenance

This is an independent deployment repository containing the complete
LingBot-Map source tree and an integrated video-to-web application. It is
published as a new repository rather than through GitHub's fork mechanism.

The model implementation, benchmark suite, examples, paper, and original
documentation were imported from:

- project: `robbyant/lingbot-map`
- upstream commit: `bfcd0f20383d3a35cc9757a36ab1d5b6e5064df4`
- license: Apache License 2.0 (`LICENSE.txt`)

The one-command launcher, weight integrity automation, CUDA broker integration,
API/job layer, minified browser viewer, container stack, Cloudflared deployment,
tests, and operations documentation are maintained in this repository.
